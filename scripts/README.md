# Backend 스크립트 상태

2026-11-27 문서 정리 기준. 이 디렉토리의 실행 코드는 아직 이전 구현에 속한다.

`sync-contracts.sh`와 `sync_contracts.py`는 분리된 Auth/API 앱에 이전 계약을 복사하는 도구다. 원본 계약 디렉토리가 삭제되어 새 세션 구조의 준비·검증 명령으로 사용할 수 없다. 이번 작업에서 스크립트나 테스트 복사본을 수정·실행하지 않았다.

새 계약과 동기화 방식은 [감사 이벤트 설계](../docs/audit-event-design.md)를 구체화한 뒤 정한다. 새 모듈·계약이 구현되기 전까지 실행 예시는 제공하지 않는다.
